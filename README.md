## 更新のルール

1. **main に直接上げない。** 修正は必ず別ブランチに上げ、プルリクエスト（修正案）を作る
2. Netlify が修正案ごとに確認用ページ（Deploy Preview、クレジット0）を作る
3. 確認用ページを見て問題がなければ、**代表が** プルリクエストを Merge する → 本番に反映（1回15クレジット）
4. 崩れたら Netlify の Deploys から前の版を選び「Publish deploy」で戻す（無料）
5. 案件一覧などシートの「ウェブに公開」CSV を読むページは、本番のCSVで動作確認してから修正案を出す。シートの列構成を変えた直後は出さない
